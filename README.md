# Sales Data Cleaning and Analysis

## About the Project

This is a beginner-level data analysis project built using Python and Pandas.

The project focuses on cleaning a sales dataset, handling missing and invalid values, identifying duplicate records, and analysing total revenue generated by each product.

It demonstrates how Python and Pandas can be used to perform basic data cleaning and data analysis tasks.

## Technologies Used

- Python
- Pandas

## Dataset

The project uses a sample sales dataset created using Pandas.

It contains the following columns:

- `order_id` – Unique order identifier
- `product` – Name of the product
- `quantity` – Number of units sold
- `unit_price` – Price per unit
- `city` – City where the order was placed

## Operations Performed

1. **Data Inspection**
   - Checked dataset dimensions using `shape`.
   - Inspected column names, data types and missing values.
   - Used `info()` and `isnull()` for data inspection.

2. **Duplicate Detection and Removal**
   - Identified exact duplicate records.
   - Removed duplicate rows using `drop_duplicates()`.

3. **Data Cleaning**
   - Standardized product names using string operations.
   - Identified missing and invalid values.
   - Separated valid sales records from suspicious records.

4. **Revenue Calculation**
   - Created a new `revenue` column.
   - Calculated revenue using quantity × unit price.

5. **Sales Analysis**
   - Grouped sales by product.
   - Calculated total revenue for each product.
   - Sorted products by revenue in descending order.

6. **Exporting Results**
   - Exported the final sales report to a CSV file using `to_csv()`.

## How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd sales-data-analysis
```

3. Install the required library:

```bash
pip install pandas
```

4. Run the Python script:

```bash
python sales_analysis.py
```

The script generates a `sales_report.csv` file containing total revenue by product.
